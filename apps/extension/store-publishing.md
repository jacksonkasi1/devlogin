Upload the extension ZIP attached to the GitHub release to the existing Global Login listing. The three PNGs in `apps/web/public/store/` are ready to upload in the screenshots section. Use the 128 px image in `apps/extension/public/icon/` for the listing icon.

- Product name: Global Login
- Summary: Organize project logins, fill signup forms, and keep private notes, identities and developer credentials in one place.
- Website: https://devlogin.peacockindia.in/
- Privacy: https://devlogin.peacockindia.in/privacy
- What's new: https://devlogin.peacockindia.in/releases

Review the current listing's permissions and privacy declarations against this release before submitting it for Chrome Web Store review. The GitHub release distributes the ZIP; submission to the store is a separate step.
