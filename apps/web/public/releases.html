What's new

Version 1.1.0 · November 2026

Find and organize logins

  • Create collections across projects using a shared tag. Search by collection or tag and sort by suggested, newest, oldest, last edited, or name.
  • See who added or edited a login, including edits through an MCP token.
  • Refetch one website icon or refresh the vault from the menu or MCP.

Your personal vault

  • Save identities, cards, API credentials, secure notes, and other private items.
  • Generate a password from Tools or a signup form. Review a profile before using it on a website.
  • Upload private attachments up to 50 MB each, rename, download, or delete them.

In the browser

The toolbar has a theme switch, hover actions and a separate login editor. New installations include a practice tutorial.
