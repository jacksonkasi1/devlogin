Global Login privacy

Google sign-in identifies your account to the Global Login server configured in the extension. Approved users share project logins. User permissions control editing, backups and MCP access. Personal vault items and attachments are scoped to the user who created them.

On enabled sites the extension can suggest matching logins, fill credentials, and offer to save or update a submitted password. Pending credentials expire. Saving requires confirmation. Identity capture and filling require an explicit action on the chosen form. You can exclude websites or remove the extension’s site access in your browser.

The server encrypts login passwords and personal item contents before storing them in D1. Titles, tags, account metadata and activity are available to their intended viewers. Files are stored in private Cloudflare R2 storage. You can delete individual items and files. Backup retention depends on the host.

Website icon discovery reads public site metadata and can request an image from the site, its CDN or Google's favicon service. Public fallback requests use the hostname. Opening the optional temporary inbox takes you to an external provider. Connecting an AI client allows that client to access tools using your personal MCP token. Revoke the connection by resetting the token.

For access or deletion requests, contact the administrator of your Global Login deployment.
