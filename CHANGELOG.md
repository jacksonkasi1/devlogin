# Changelog

## 1.1.0 · 2026-11-22

- Restored the Global Login globe and keyhole on the website and browser toolbar. The popup and dashboard share the login list, credential rows, menus and editor.
- Added a separate extension editor, first-run tutorial, light/dark shortcut and hover actions.
- Added project and login tags, cross-project collections, sorting and attributed login activity. Historical records retain their original dates.
- Expanded website icon discovery and added single and bulk refresh through the website, extension and MCP.
- Added private personal items, signup identity assistance, a password generator and a shortcut to an external temporary mailbox.
- Added private R2 file attachments with a 50 MiB limit. The website supports upload, download, rename and delete. Documents can reference an uploaded file.
- Added role-checked MCP updates, including batch edits, preferences, collections, personal vault items and file management.
