# Changelog

## 1.2.1 · 2026-11-22

- Create collections from the overview, edit them from their cards, and choose a collection emoji or icon.
- Personal items and files show who can access them. Category selection and file actions use compact icons.
- Center the extension login and tools windows over the originating browser window.

## 1.2.0 · 2026-11-22

- Browse projects and collections as cards. Organize logins within a project or group entire projects together.
- Reveal the saved password in the editor, scroll long forms, and manage private attachments on existing logins.
- Recheck edit permissions before offering to save a login and respect saved localhost project identities.
- Added category icons to the web and extension item menus.

## 1.1.3 · 2026-11-22

- Refined the Other logins tab with curved shoulders and an aligned chevron.

## 1.1.2 · 2026-11-22

- The floating prompt now shows the login title and username on separate lines. Other logins opens a searchable panel with keyboard selection.

## 1.1.1 · 2026-11-22

- Added a dismissible floating login chooser on matching password sign-in forms. Toggle it in extension Settings.
- Prefer larger declared website icons, including Apple touch icons, over small ICO files.

## 1.1.0 · 2026-11-22

- Restored the Global Login globe and keyhole on the website and browser toolbar. The popup and dashboard share the login list, credential rows, menus and editor.
- Added a separate extension editor, first-run tutorial, light/dark shortcut and hover actions.
- Added project and login tags, cross-project collections, sorting and attributed login activity. Historical records retain their original dates.
- Expanded website icon discovery and added single and bulk refresh through the website, extension and MCP.
- Added private personal items, signup identity assistance, a password generator and a shortcut to an external temporary mailbox.
- Added private R2 file attachments with a 50 MiB limit. The website supports upload, download, rename and delete. Documents can reference an uploaded file.
- Added role-checked MCP updates, including batch edits, preferences, collections, personal vault items and file management.
